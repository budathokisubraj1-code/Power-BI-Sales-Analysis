# Power BI Sales Analysis

## Project Overview

This project uses Microsoft Power BI to analyze sales data and present business insights through interactive dashboards.

The report focuses on sales performance, product analysis, customer behavior, and payment analysis. It uses interactive slicers, KPI cards, charts, and DAX measures to support business decision-making.

## Dashboard Pages

### 1. Sales Performance
- Overall sales performance
- Key Performance Indicators (KPIs)
- Sales trends over time
- Sales performance by region
- Sales channel analysis
- Interactive filters for year, sales channel, and region

### 2. Product & Sales Analysis
- Top 10 products by revenue
- Product category revenue analysis
- Product revenue and profit comparison
- Revenue by sales channel
- Product performance analysis

### 3. Customer & Payment Analysis
- Customer count by segment
- Top customers by revenue
- Customer segment analysis
- Regional customer analysis
- Payment status breakdown

## Tools & Skills Demonstrated

- Microsoft Power BI
- Data visualization and dashboard development
- Data modeling

- Interactive slicers and filters
- Sales and customer performance analysis
- Business intelligence and reporting

## How to Use

1. Download the `Second Project.pbix` file from this repository.
2. Open it using Microsoft Power BI Desktop.
3. Explore the three dashboard pages.
4. Use the slicers to interact with the report and analyze different aspects of the sales data.

## Project Objective

The objective of this project is to demonstrate practical Power BI skills by transforming sales data into interactive visual reports that help understand business performance, product contribution, customer behavior, and payment trends.
